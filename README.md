# .yesterday — launch site

Static landing page for the .yesterday camera. One `index.html`, images and audio in `assets/`. No build step.

- Deployed on Vercel from this repo: every push to `main` redeploys.
- The two email sign-up forms are not connected to a mailing list yet. Search `index.html` for `TODO: send` to find the two spots.
- Footer links for Instagram and Privacy still point to `#`.
